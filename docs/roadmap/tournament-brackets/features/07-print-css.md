# Feature 07: Print CSS

## Description

Tournament organizers often print brackets for venues, notice boards, and offline use. Print output should be first-class.

## Requirements

- Add print-friendly styles.
- Hide toolbar and interactive-only controls in print.
- Use high-contrast light colors.
- Avoid clipping large brackets where possible.
- Document browser print recommendations.

## Acceptance Criteria

- Printed single-elimination bracket is readable.
- Toolbar does not appear in print.
- Dark mode does not produce low-contrast printed output.
- Docs include print instructions.
