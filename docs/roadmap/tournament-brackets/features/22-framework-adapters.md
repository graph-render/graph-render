# Feature 22: Framework Adapters Decision

## Description

Vue/Svelte adapters could expand reach, but they should not distract from becoming the best React bracket library first.

## Requirements

- Revisit only after React package has meaningful adoption.
- Keep core/generator logic framework-agnostic.
- If implemented, start with generic graph rendering, not full tournament-tree parity.
- Use demand signals from issues/downloads before starting.

## Acceptance Criteria

- Decision document compares demand, maintenance cost, and implementation scope.
- No adapter work blocks React bracket roadmap.
- Shared core APIs are ready for framework reuse.
